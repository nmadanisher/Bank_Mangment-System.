# 🏦 Bank Management System

A simple **Bank Management System** web app built for the **Web Technology** course using HTML, CSS and vanilla JavaScript. No backend needed — data is saved in the browser's `localStorage`.

## Features
- Admin login (demo: `admin` / `admin123`)
- Open a new account (Savings / Current) with CNIC validation
- Deposit, withdraw and transfer money, with insufficient balance check
- ATM card style account cards
- Balance bar chart (drawn with Canvas)
- Per-account transaction history with print statement
- Search accounts, delete accounts
- Dark / light mode, animations, responsive design

## Technologies Used
| Technology | Purpose |
|-----------|---------|
| HTML5 | Page structure and forms |
| CSS3 | Styling, flexbox, responsive layout |
| JavaScript (ES6) | Logic, DOM manipulation |
| localStorage | Saving data in the browser |

2. Open `index.html` in any browser.
